# Firebase Meetup website

Production static build of gogus474/firebase-gtk-web-start-182y4j.

To activate GitHub Pages, open the repository Settings → Pages. Under Build and deployment, select Deploy from a branch, gh-pages, /(root), then Save.

Expected site address after a successful deployment: https://gogus474.github.io/firebase-gtk-web-start-182y4j/

The HTML, CSS, JavaScript, and RSVP email sign-in UI were verified in Chromium. Authentication and Firestore access depend on the Firebase project configuration and have not been verified with an account.
